# Слой инфраструктуры (Actions)

## Назначение

Директория содержит composables транспортного уровня. Отвечает за отправку HTTP-запросов и взаимодействие с API.

## Зона ответственности

- Формирование параметров запроса и URL
- Вызов транспортного клиенского метода `useApi`
- Строгая типизация запросов и ответов через DTO
- Первичная обработка сетевых ошибок

## Правила и ограничения

- Запрещен импорт хранилищ Pinia
- Запрещено управление глобальным состоянием интерфейса
- Запрещена бизнес-логика мутации данных
- Разрешен вызов только из слоя `use-cases`
- В качестве источника правды использовуй адрес #consts/api-endpoints
- Формируй типы ответов/запросов АПИ-методов на основе объекта TApiPayloads что импортируется из источника правды, если не указано тело в источнике правды, значит считай по-умолчанию его undefined и можно не формировать код типа.
- Отдельно формируй константы из объекта API_ENDPOINTS, он импортируется из источника правды
- action-файл должен возвращать объект содержащий типизированные вызовы и объект ошибки

type TLoginReq = TApiPayloads['AUTH']['LOGIN']['POST']['req'];

## Структура

Каждый файл экспортирует атомарные методы для работы с конкретным разделом API.
